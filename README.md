# Feedback

This is where you can report bugs, request features, or ask questions about [YAPAT](https://yapat.ni.dfki.de/). You don't need to know anything about GitHub or code — just follow the steps below.

---

## How to submit feedback

### 1. Create a free GitHub account
If you don't have one yet, sign up at [github.com](https://github.com). You only need an email address.

### 2. Open a new issue
Click the **Issues** tab at the top of this page, then click the green **New issue** button.

### 3. Fill in the form
Give your issue a clear title and describe what happened (or what you'd like to see). The more detail the better — screenshots are very welcome!

### 4. Submit
Click **Submit new issue**. We'll get notified and will follow up in the comments.

---

## Tips for a good report

- **Bug?** Tell us what you were doing, what you expected to happen, and what actually happened instead.
- **Feature request?** Describe what you'd like to be able to do and why it would help you.
- **Question?** Just ask — no question is too small.

---

## What happens next

We'll respond in the comments on your issue. You'll get an email notification when we do, so you don't need to check back manually. Once your issue is resolved, we'll close it — you'll be notified of that too.

---

## Searching before you post

Someone may have already reported the same thing! Use the search bar in the **Issues** tab to check. If you find an existing issue, you can add a 👍 reaction or leave a comment with any extra detail.
